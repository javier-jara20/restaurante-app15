# 🍽️ Restaurante App

## ✨ Descripción

Una pequeña app de restaurante hecha con Python y Tkinter para gestionar usuarios, productos y ventas de forma sencilla.

## 🚀 Instalación

- ✅ Asegúrate de tener Python 3 instalado.
- ✅ Abre la carpeta del proyecto.
- ✅ Instala las dependencias necesarias si aplica en tu entorno.
- ✅ Ejecuta la app con:

```bash
python main.py
```

## 🎯 Cómo usarlo

- 🧑‍💼 Inicia la aplicación.
- 🔐 Ingresa con un usuario válido.
- 🛒 Explora la interfaz principal para ver y manejar el restaurante.
- 📦 Usa los datos de productos y usuarios cargados desde la carpeta `datos`.

## 🌟 Nota rápida

Es un proyecto simple, visual y práctico para aprender estructura de app, clases y manejo de datos en Python.
